Broken Azure Environment

Lab Overview
• Cloud: Azure
• Duration: 90 minutes
• Exercises: 3 (Troubleshoot and secure the storage account, Create the completion file on labvm, Inline knowledge checks)
• Validations: 2
• Deployed services: Resource Group, Virtual Network, Subnet, Network Security Group, Public IP Address, Network Interface, Windows Virtual Machine, Storage Account
• Scenario: Learners investigate a deliberately insecure Azure Storage account in the Azure portal, enable secure transfer, and disable public network access. They then connect to the Windows VM named labvm and create the exact required completion file before answering five single-choice knowledge checks.
