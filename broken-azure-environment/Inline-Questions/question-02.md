## Question
Which Azure Storage account setting should you enable to require clients to use HTTPS for data transfers?

## Options
Option 1 : Secure transfer required
Option 2 : Public network access
Option 3 : Allow Blob anonymous access
Option 4 : Minimum TLS version set to 1.0

## Answers
Option 1

## Correct Answer Feedback
Option 1 is correct answer, Secure transfer required enforces HTTPS for requests to the storage account and helps prevent data from being sent over an unencrypted connection.

## Incorrect Answer Feedback
Selected Option is not correct Option 1 is the correct answer. Public network access and anonymous access control exposure, while the minimum TLS version controls the TLS protocol version; neither setting is the secure-transfer requirement.
